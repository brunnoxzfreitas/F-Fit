# F-Fit — Static serve & fallback

Use this file to test the app locally without Node/Vite. The project contains a static fallback UI (`fallback.css` + `fallback-app.js`) that runs when the Vite dev module (`/src/main.tsx`) is not available.

## Serve locally (quick)

From the project root (where `index.html` is):

Python 3 built-in server:

```powershell
python -m http.server 5173
# or
python3 -m http.server 5173
```

Open in browser: http://localhost:5173

Node (if you install Node later):

```powershell
npx serve -s . -l 5173
# or
npx http-server -p 5173
```

## What to check in the browser

- DevTools → Console: look for messages:
  - `Loaded Vite dev app (src/main.tsx)` — real dev app loaded.
  - `Vite dev module not available — loading fallback UI` or fallback logs — fallback loaded.
- Network tab: ensure `index.html`, `fallback.css`, `fallback-app.js` return 200 and proper `Content-Type`.
- Run these in Console to validate:

```js
!!document.getElementById('root')
fetch('/api/users').then(r=>r.json()).then(console.log).catch(console.error)
```

## Hosting notes

- If you uploaded the raw dev files (imports to `/src/main.tsx`) but didn't run `npm run build`, the hosted page may be blank. Either deploy the `dist` from `npm run build` or use the static fallback files included here.
- If hosting in a subdirectory (e.g. `https://example.com/app/`) add a `<base href="/app/">` line to `index.html` or adjust the injected paths.
- Ensure your host serves `.js` as `text/javascript` and `.css` as `text/css`.

## Deploy to GitHub Pages (recommended)

This repository includes a GitHub Actions workflow that builds the app and publishes the `dist` folder to GitHub Pages when you push to `main`.

1. Push your code to the `main` branch on GitHub.
2. The workflow `.github/workflows/gh-pages.yml` will run `npm ci` and `npm run build`, then publish `dist` to GitHub Pages.

Notes:
- The build sets `PUBLIC_PATH` to `/<repo-name>/` so routing will work on GitHub Pages. If you host under a different path, set `PUBLIC_PATH` in the workflow or in your repo settings.
- If you prefer manual deploy, run locally:

```bash
npm ci
npm run build
# then publish the contents of the `dist` folder to your Pages hosting
```
